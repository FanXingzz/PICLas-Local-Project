# 100 μm 氦气放电优化短测

基准和优化两组均从同一份 **1.25 ns HDF5** 续算到 **1.275 ns**。该检查点来自 +6000 V、2/5/2 ns 的 100 μm 石英管钨针算例，含 80,664 个宏粒子及石英表面电荷源项。检查点副本及校验值见 [输入记录](inputs/checkpoint.json)。每次测试另外复制检查点到新的工作目录。

| 项目 | 基准 | 优化 |
| --- | --- | --- |
| 求解器 | 原正式计算使用的 PICLas 4.3.0，运行前核对哈希 | 独立编译的相同 PICLas 4.3.0，气相配对遍历仅访问可反应的物种组合 |
| 配对 | 原单元内双循环 | 按物种建立后继索引，保留可反应配对的原顺序、权重和抽样规则 |
| MPI | 6 进程 | 6 进程，按实测单元耗时动态再分区 |
| 负载均衡 | 关闭 | 每个 5 ps 输出周期前采样 100 步，超过 10% 的负载偏差时触发，最多 4 次。使用 HDF5 路径恢复石英电荷 |
| 网格与物理输入 | 同一个网格、0.025 ps 步长、原 +6000 V 波形、反应网络和全部系数、初始参数与界面参数 | 同基准 |

每组目标为 **1000 步**。5 ps 是短测的状态输出间隔，两组一致。动态再分区会改变宏粒子的进程归属和随机数流，两组电子密度和电流按统计量对比。是否实际发生再分区以短测计数为准。

## 执行与核对

用户确认后，在 WSL 从本目录执行 `bash run_benchmark.sh`。脚本沿用正式求解的全局运行锁。可用的六进程计算槽空出后，脚本依次运行两组，每组写入独立目录。构建方式为 `bash build_solver.sh`，使用独立构建路径和单个低优先级编译作业。

测试完成后，从 Windows 运行 `python -B compare.py "runs/批次目录"` 生成以下对照结果。

- **平均墙钟时间/步**，计入初始化、输出和动态再分区成本。
- **电子密度**，包括气体域平均密度时间序列、末帧单元峰值和 25 μm 轴向分箱的截面平均密度。
- **两针导电电流**，逐步扣除位移电流，并用粒子通量和二次发射电流核对，再输出 1 ps 时间平均。
- **实际再分区次数**，从求解器的单元计时记录读取。

基准和优化的参数与模型记录分别在 [baseline](baseline/MODEL_SETTINGS.md) 和 [optimized](optimized/MODEL_SETTINGS.md)。原始截面、反应清单和基准源码补丁随输入副本归档。

## 宏粒子权重

基准和配对优化组保留当前逐步合并的配置，每个单元每种物种的合并阈值为 100。宏粒子超过阈值时，PICLas 将物种权重重新分配给留下的宏粒子。更多单元开始电离时，全域宏粒子数仍会增长。

独立权重试验将 He⁺ 和 He* 的阈值降到 **64**，电子、He₂⁺ 和 He₂* 保持 100。用同一份检查点和已编译的优化求解器，通过 `bash run_benchmark.sh vmpf_hep_hestar64` 运行。求解完成后用 `python -B compare.py "runs/权重批次" --vmpf-reference "runs/对照批次/optimized"` 比较阈值 100 和 64。
