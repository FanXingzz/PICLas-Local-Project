# 100 μm 氦气放电动态宏粒子权重短测

本算例用独立 PICLas 4.3.0 求解器，从与固定阈值优化组相同的 **1.25 ns** 检查点续算到 **1.275 ns**。两组用六进程、原网格、0.025 ps 步长、+6000 V 波形和原反应网络。每次运行写入新的 `runs` 子目录，保存实际使用的权重参数、物理输入、网格、检查点、模型设置、求解器哈希和源码补丁。

每个物种的目标权重为检查点平均权重乘以 `max(1, 当前加权粒子数 / 检查点加权粒子数) ^ 指数`，并限制最大增重倍率。当前物种总量由六进程归约。合并只在同单元同物种内进行，保留局部总权重，并沿用 PICLas 的动量和动能校正。针尖保护范围内的电子以及动能达到 19.82 eV 的电子沿用固定阈值。

| 参数 | 默认值 | 作用 |
| --- | ---: | --- |
| 增重指数 | 0.5 | 真实粒子数增至 4 倍时，目标平均权重增至 2 倍。 |
| 更新间隔 | 50 步 | 每 1.25 ps 计算一次新的自适应权重目标。 |
| 每组合并后最少宏粒子 | 16 | 限制一次自适应合并能压缩到的最低采样数。 |
| 目标权重倍率上限 | 2 | 自适应目标平均权重最多取检查点平均权重的 2 倍。 |
| 电子针尖保护宽度 | 25 μm | 从两侧针尖各向间隙内量取。该范围及针尖后方的电子沿用固定阈值。 |
| 固定合并阈值 | 每种 100 | 每步检查该物种在各单元的宏粒子数。超过阈值就按原合并机制降至该值。 |

固定阈值可对电子、He⁺、He₂⁺、He*、He₂* 分别设置。填 0 会关闭该物种的固定和自适应合并。指数设为 0 时，各物种继续使用各自的固定阈值。保护区、采样下限和既有合并规则会使实测物种平均权重与目标值有所差异。

## 在工作台调整

在 VS Code 工作台右侧打开 **动态宏粒子权重**。可展开 **固定合并阈值** 设置各物种阈值，再点击 **保存权重参数** 或 **运行权重短测**。短测完成后在 **显示内容 → 动态权重短测** 选择该次运行，查看电子密度和模型设置。运行参数保存到该次独立目录的 `settings.json` 和 `parameter.ini`。

命令行可在本目录用 `bash run_short.sh` 运行。独立求解器由 `bash build_solver.sh` 构建。Windows 中用 `python -B compare_runs.py "runs/运行目录"` 与固定阈值优化组比较。结果记录每步耗时、宏粒子数量和权重、电子密度、加权高能电子比例、直接电离计数及两针导电电流。控制器实际合并数量和目标权重记录在每次运行的 `AdaptiveVMPF.csv`。

构建可通过 `PICLAS_UPSTREAM`、`PETSC_DIR` 和 `PICLAS_JIA_ADAPTIVE_SOLVER_ROOT` 指定源码、PETSc 和独立构建目录。首次短测需要取得原 1.25 ns 检查点及配套 HDF5 输入，可把完整的 `He_D100um_Pos6000V_Optimized_Restart1250ps` 归档放回同级目录，也可在 WSL 将 `PICLAS_JIA_VALIDATION_REFERENCE` 指向该归档目录。
