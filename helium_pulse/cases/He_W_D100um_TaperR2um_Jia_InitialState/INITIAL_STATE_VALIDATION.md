# Jia 初始状态验证

独立 PICLas 4.3.0 求解器用六个 MPI 进程完成三次 6 ps 短算。默认算例采用实际 +1500 V 脉冲的上升斜率，6 ps 时施加电压为 4.5 V。两个定向离子束分别用来检查三处界面。 [默认短算](runs/20261112-140920-pilot-e4wEvH/) · [验证数据](review-checks.json)

## 初始粒子

从 0 ps HDF5 读取粒子物种和权重，并按圆柱种子体积折算。带电粒子的全域净电荷为 0 C。

| 物种 | 宏粒子数 | 折算数密度（m⁻³） |
| --- | ---: | ---: |
| e⁻ | 2048 | 2.0000×10¹³ |
| He⁺ | 1024 | 1.0000×10¹³ |
| He₂⁺ | 1024 | 1.0000×10¹³ |
| He* | 256 | 2.4627315×10¹⁴ |
| He₂* | 256 | 2.4627315×10¹⁴ |

两种亚稳态权重从 7.38954455 校正为 7.39039944，对应背景氦的 (10^{-11}) 摩尔分数。带电粒子的权重为 0.07502238。默认短算的电子和总离子收支最大差为 (1.46\times10^{-13}) 个加权粒子。 [Jia 等，第 2 节](https://doi.org/10.1088/1361-6463/ac9eca)

## 定向撞击与石英充电

每次在三处界面前各放置 6000 个同权离子宏粒子。定向测试关闭粒子感受的电场，保留背景碰撞及表面模型，临时提高合并阈值以保持撞击粒子等权。表中发射率为发射电子数除以相应的实际撞击数。

| 界面 | He⁺ 设定 | He⁺ 测得 | He₂⁺ 设定 | He₂⁺ 测得 |
| --- | ---: | ---: | ---: | ---: |
| 高压钨针 | 0.25 | 1450/5859 = 0.2475 | 0.10 | 601/5995 = 0.1003 |
| 接地钨针 | 0.25 | 1453/5852 = 0.2483 | 0.10 | 592/5963 = 0.0993 |
| 石英内壁 | 0.02 | 139/5878 = 0.0236 | 0.02 | 128/6000 = 0.0213 |

六项发射率均落在相应设定值的三倍二项抽样标准差以内。用离子入射、电子入射和二次电子发射计算 (Q_mathrm{quartz}=e(N_i-N_e+N_mathrm{SEE}))，与 HDF5 中介质场源项的轴对称体积分比较。三次短算中最大差为 (2.15\times10^{-30}) C。 [He⁺ 定向短算](../../verification/Jia_InitialState_SEE_HePlus/runs/20261112-140758-pilot-le598S/) · [He₂⁺ 定向短算](../../verification/Jia_InitialState_SEE_He2Plus/runs/20261112-140825-pilot-XJqROe/)

默认短算的 0、2、4、6 ps 四帧电子密度已在工作台读取并渲染，保存四个 HDF5 状态和八个 VTU 文件。界面验证约束的是当前设定值的实现与电荷守恒。+1500 V 完整脉冲已开放手动启动。
