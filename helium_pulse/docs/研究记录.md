## 100 μm 石英内壁完整脉冲对照

100 μm 基准为常压氦气、石英管内径 100 μm、外径 200 μm、同轴钨针尖半径 2 μm、针尖间距 1 mm。两组使用相同的 1120 单元轴对称网格、1e16 m⁻³ 初始种子密度、1 eV 电子初温和钨针设置。六个 MPI 进程以 0.1 ps 步长求解 +1500 V 的 2 ns 上升、5 ns 平顶、2 ns 下降脉冲。

| 折算粒子数 | 全吸收内壁 | 总返回内壁 |
| --- | ---: | ---: |
| 2 ns 气相电子 | 13,391 | 20,294 |
| 9 ns 气相电子 | 0 | 375 |
| 全程石英壁电子净损失 | 77,161 | 79,861 |
| 全程体电离电子/离子对 | 33,235 | 49,815 |

总返回组上升沿末的壁面净损失较低，电子存留和累计体电离增加。两组气相电子总数均未超过初始值，未形成贯穿击穿。全吸收组在 7.7898 ns 耗尽电子，总返回组到 9 ns 剩 10 个宏粒子。以上为当前单次脉冲、有效壁面参数和网格下的结果。

两组保留 He⁺ 吸收、石英相对介电常数 3.8 及动态充电。总返回组采用 PICLas 模型 11，按低能石英数据的拟合 δ(E)=0.8+0.2E/35 计算电子返回，E 以 eV 计。该产额合并背散射和二次发射。粒子收支和每帧壁面沉积电荷均已核对。轴对称追踪的局部修补、适用范围和相近毛细管文献见 [壁面模型依据](quartz-wall-literature.txt)。

## 当前二维轴对称针—针算例

工作台默认使用二维 x-r 轴对称求解，计算 r ≥ 0 的管腔与石英壁，x 为针间轴向。示例为管内径 50 μm、针尖半径 2 μm、针距 1 mm。管外径 150 μm、管长 1.3 mm。旋转轴使用 symmetric_axis，存储层两侧使用 symmetric_dim，粒子和 Poisson 方程均启用轴对称设置。

「网格」只设置轴向与径向参数，包括圆头轴向和径向分段、管腔与石英的径向层数、贴壁首层比例和轴向最大尺寸。PICLas 的 HDF5 格式用单层六面体存储，实际求解维度由 Particles-Symmetry-Order = 2 和 Particles-Symmetry2DAxisymmetric = T 指定。电荷沉积使用旋转体单元体积，初始种子在圆柱体内均匀采样后映射到径向坐标，其半径采样遵循环带体积。

二维 864 单元的 6 ps 短验证已检查过轴对称粒子位置、+4.5 V 终点及结果导出，短验证输出已清理。正式完整脉冲与静电对照仍可回放。

二维三档 1 V 静电检查中，粗到中、中到细的采样相对 L2 差异分别为针尖电场 4.125%、2.910%，近壁电场 1.737%、1.031%，壁法向电场 2.968%、1.209%。这些是静电检查结果，击穿和放电传播仍需时间步、种子与粒子统计收敛验证。[二维采样数据](../cases/axisymmetric_d50_fields.csv)

## 钨针全气隙预电离与电极发射

新模型在 [He_W_D50um_R2um_Gap1mm_Pos1500V_Seed1e16_SEE015_Refl020](../cases/He_W_D50um_R2um_Gap1mm_Pos1500V_Seed1e16_SEE015_Refl020/)，沿用原几何、网格、氦气条件和正脉冲。两根钨针使用 He⁺ 诱导产额 0.15、入射电子镜面反射概率 0.20。初始气隙内均匀放置等量电子和 He⁺，密度 1e16 m⁻³，电子初温 1 eV。初始各 2048 个宏粒子，宏粒子权重约 9.1893；合并阈值设置为每单元每物种 100。

种子与有效系数参考 [Donkó 等常压纳秒微放电研究](https://doi.org/10.1088/1361-6595/aac301)，并与 [Hagstrum 的洁净钨 He⁺ 发射实验](https://doi.org/10.1103/PhysRev.96.325) 对照。实际钨针的表面条件未知，产额、反射概率和 0–4 eV 发射能量范围均为探索设定。[文献与模型依据](../cases/He_W_D50um_R2um_Gap1mm_Pos1500V_Seed1e16_SEE015_Refl020/literature-review.txt)

本地 PICLas 模型 7 已能接受 He⁺ 的常数产额；patch_electrode_reflection.py 增加了独立的电子反射概率，默认零保持原求解行为。接地电极全吸收、全反射及离子发射三个极限的核对见 [电极验证摘要](../verification/electrode-verification-summary.json)。每次完整运行保存物理参数、模型说明和求解器补丁快照。

## 历史基准算例的几何与物理模型

- 101325 Pa、298 K 的均匀氦气背景，数密度约 2.463 × 10²⁵ m⁻³。
- 左针加正脉冲，右针接地。两针同轴，针尖间距 1000 μm。用半径 20 μm 的半球端面与针杆相切，网格用平面面片离散圆弧。
- 两块石英板相距 100 μm，板厚暂取 60 μm。把 100 μm 石英管解释为内径，外径暂取 150 μm。针位于石英管中心轴，石英管嵌入上下两板。板间管外空间同样填氦，模型以计算域外壁截断，外壁使用零法向电场和开放粒子边界。
- 35,548 个共形六面体，包含 16,036 个氦气单元和 19,512 个石英单元。石英区相对介电常数暂取 3.8，界面吸收带电粒子并沉积电荷。几何假设在 [geometry.json](../geometry.json)，修改几何后应重建网格并检查种子区仍在高压针尖前方的气腔内。
- PICLas 4.3.0（514af4c），Poisson/HDG + PETSc/MUMPS、Leapfrog + MCC。使用同一提交中的 He 回归算例 CHEM_RATES_XSec_Chem_Elec-He-e 的两个 HDF5 数据库。模型包括 e–He 碰撞、激发及直接电离、He⁺–He 弹性与反向散射。初始在高压针尖前方 20–40 μm 注入 80 个电子和 80 个 He⁺ 宏粒子，宏粒子权重 20。当前初版的化学和源项限于上述机制，He₂⁺、亚稳态逐级电离、杂质、二次电子和预电离强度均需在定量研究中考察。若上升沿期间种子被壁面耗尽，须用有物理依据的预电离或电极发射条件评估对结果的影响。
- 默认 0–2 ns 线性上升到正峰值，2–7 ns 平顶，7–9 ns 线性回到 0 V。实际模型终止时间 9 ns，初始时间步 0.1 ps，共约 90,000 步，每 0.25 ns 写场状态。网格和步长需用 Debye 长度、局部场梯度、粒子跨单元步长与电流收敛性检查。

## 峰值电压与击穿判据

Chen 等在常压氦气中用 4.2 mm 针—针间距和 200 ns 重复脉冲测试了 3–6 kV 施加峰值。他们给出的直流参考场约为 4 kV/cm，其 1 mm 均匀场尺度为约 0.4 kV。该文使用的电极形状、脉冲历史和本模型不同。Huang 等的常压氦平板实验表明，上升速率影响击穿过程。 [Chen 等原文](https://www.osti.gov/servlets/purl/1787665) · [Huang 等，2015](https://doi.org/10.1088/0022-3727/48/12/125202)

默认高压针峰值 **+1.5 kV**，对应名义间隙平均场 15 kV/cm 和上升沿幅度斜率 0.75 kV/ns。可先取峰值幅度 0.5、1.0、1.5、2.0、3.0 kV 做探索扫描，固定脉宽和极性，初步找到击穿与未击穿之间的区间，再对区间细化。把电荷电流持续上升、电子数净增长和气隙内电离通道的形成作为联合判据，记录首次满足判据时的瞬时针间电压、时刻和施加峰值。用不同初始种子和更细的网格、时间步检查重现性。

- FieldAnalyze.csv 包含施加电压 BFO-boundary 和各面位移电流 ElecDisplCurrent。
- SurfaceAnalyze.csv 包含粒子通量及 TotalElectricCurrent。用同一边界上的总电流减去位移电流可检查传导分量。
- PartAnalyze.csv 与 HDF5/VTU 场和单元数据可联合查看电子数、电子密度、电势和电场。

## 在 VS Code 编译

1. 在 Windows VS Code 中选择“文件 → 打开文件夹”，打开 E:\PICLas_Local_Project\helium_pulse。
2. 按 Ctrl+Shift+B 运行默认构建任务 **PICLas: Build helium pulse solver**。快捷键有冲突时，可按 Ctrl+Shift+P 搜索 **Tasks: Run Build Task**。终端出现 `SUCCESS: PICLAS BUILD COMPLETE!` 表示编译成功。任务通过 Ubuntu 24.04（WSL）调用 CMake 和 Ninja，最多使用六个编译进程。
3. 需要重建网格时，按 Ctrl+Shift+P，选择 **Tasks: Run Task**，再选 **PICLas: Build helium mesh**。在工作台修改峰值或脉宽后，保存参数并重新运行即可。

求解器位于 WSL 的 `/home/fanxing/piclas_projects/helium_pulse_workspace/build/bin/piclas`。求解最多使用六个 MPI 进程，每个进程使用单线程数值库，运行锁避免同时启动两个氦气计算。
